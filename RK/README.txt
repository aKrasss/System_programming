РК 1 — Системное программирование

Раздел 1 — команды Linux (bash): файлы 1_1.sh ... 1_5.sh
  Команды выполняются в каталоге sandbox, где лежат Task_1, Task_2, Task_3.
  Можно вводить по одной в терминале или запустить файл целиком:
      cd sandbox && bash ../1_1.sh
  Каждая задача рассчитана на «свежий» sandbox (задачи независимы).
  Подготовка sandbox:  mkdir sandbox && cd sandbox && touch Task_1 Task_2 Task_3
  1_3: tar не умеет дописывать в сжатый .gz, поэтому перед добавлением List
       архив распаковывается (gzip -d) и после сжимается снова.

Разделы 2 и 3 — FASM, Linux x86-64, вызовы syscall: файлы 2_1.asm ... 3_5.asm
  func.asm — библиотека функций из лекции 4 (print_str, new_line, len_str,
  str_number, number_str, input_keyboard, exit); подключается через
  include 'func.asm' и должна лежать рядом с файлами задач.
  Сборка: make  (или вручную: fasm 2_1.asm && ld 2_1.o -o 2_1)

  ./2_1 7      -> 16       (1+3+5+7; чётное число -> ошибка)
  ./2_2 2      -> 123      (1+11+111; без переполнения до n = 19)
  ./2_3 12     -> 78       (сумма реверсированных чисел 1..12)
  ./2_4 30 3   -> 66       (3+12+21+30)
  ./2_5 12     -> 318      (сумма k*first_digit(k))

  ./3_1 <каталог> <n>   — n файлов со случайными именами
  ./3_2 <name> <n>      — name/name/name/... n раз
  ./3_3 <каталог>       — случайные файлы получают случайные имена
  ./3_4 <каталог>       — два случайных файла меняются содержимым
  ./3_5 <каталог>       — случайные файлы получают случайные права
